Biology 3315 Molecular Evolution and Phylogenetics

The Biostrings package

The first package we will deal with is Biostrings. As its name suggests, it is a package that handles biological strings. It can handle DNA, RNA, and amino acid sequences and is also capable of pattern matching, which helps with sequence look-up and alignment (albeit with limited capabilities). Biostirngs allows to import individual sequences, or FASTA files containing multiple sequences.

Biostrings utilizes a specialized class of container to store strings called Xstring. Xstring is similar to a character vector however, unlike a vector it can only house a single string.

Basic biosting sub-classes

The XString class has four sub classes:

  1. DNAstring - stores DNA sequences

  2. RNAstring - stores RNA sequences

  3. AAstring - stores amino acid sequences

  4. Bstring - stores general strings (character/alphabet agnostic)

Let’s look at a few examples of working with strings using Biostrings

> #As always, let's generate a random string and convert it to a Xstring object
> 
> string <- "This is a random string (is it random though?!)"
> 
> #Now lets call it as DNAstring
> 
> string <- DNAString(string)
Error in .Call2("new_XString_from_CHARACTER", class(x0), string, start, : key 105 (char 'i') not in lookup table

Uh-oh, an error message. This is because DNAstring is limited in its intake of characters, remember that only Bstring is character agnostic.

Let’s see which characters does DNAstring accepts

> DNA_ALPHABET
 [1] "A" "C" "G" "T" "M" "R" "W" "S" "Y" "K" "V" "H" "D" "B" "N" "-" "+" "."
> #In case you were wondering what each of those letters mean Biostrings has a function with the 
> #details.
> #Useful when designing synthetic sequences like primers
> 
> IUPAC_CODE_MAP
     A      C      G      T      M      R      W      S      Y      K      V 
   "A"    "C"    "G"    "T"   "AC"   "AG"   "AT"   "CG"   "CT"   "GT"  "ACG" 
     H      D      B      N 
 "ACT"  "AGT"  "CGT" "ACGT"

As you can see, DNAstring accepts more than just ATCG, it also accepts base categories, strand orientation (+/-) and alignment gaps.

Let’s see which characters the other two restricted sub classes accept.

One advantage of the Xstring class is that it allows to treat the sequence both as a vector and as a string. Making it easy to index, subset, and modify.

The code snippet bellow demonstrate how access and modify an XString class.

> #Lets get the first element of the AA sequence
> casain[1]
1-letter AAString object
seq: P
> #Lets subset
> casain[1:5]
5-letter AAString object
seq: PYFNI
> #Another great feature of the xstring class is that the string is mutable in the same way a vector 
> #is. Let's change the first AA to methionine.
> 
> casain[1] <- "M"
> 
> #Appending characters is done in the same way you would a character vector.
> casain[11] <- "J"
> #Reminder that gaps can also be added.
> casain[10] <- "-"
> 
> casain
11-letter AAString object
seq: MYFNIWLCV-J
> #The bonus is that because an xstring class object is treated as a string, it is easy to use functions from the stringr package to process it. Let's use str_detect to pattern match.
> #We already know that this pattern is elements 1-5 of the string
> 
> str_detect(casain, "MYFNI")
[1] TRUE
> #Can also use stringer to replace elements in the string, easier to replace a larger pattern. 
> str_replace(casain, "MYFNI","MYXGT")
[1] "MYXGTWLCV-J"

Basic Biostrings functions

The Biostrings package has some useful functions with respect to sequence processing. Let’s look at some of them.

> x <- alphabetFrequency(casain)
> #output is a named vector, not the most convinent of ways to present results.

+   geom_bar(stat = "identity", fill = "lightblue")+

Working with multiple sequences using XStringSet objects

As you know by now, bioinformaticians do not work with a single sequence rather with a lot of sequences in parallel. Biostrings offers the class XStringSet, as a container for multiple sequences. Here too it is a combination of a list and a vector, think of it as a list of XString class objects.

Just like with the XString the XStringSet offers four sub classes

  1. DNAStringSet to house DNA sequences

  2. RNAStringSet to house RNA sequences

  3. AAStringSet to house amino acid sequences

  4. BStringSet to house sets of diverse strings

This means that a BStringSet can house the DNA, RNA, and AA sequences of a particular gene.

Let’s see what it looks like

> sq1.set <- DNAStringSet(c(paste(sq1.bio),paste(sq1.bio.rev),

One of the advantages of a XStringSet is the ability to manipulate multiple sequences at the same time.

> #alphabetFrequency can calculate base frequency for every sequence, output is a matrix, let's #output as dataframe
> 
> fa.set.frq <- as.data.frame(alphabetFrequency(fa.set, baseOnly=T, as.prob = T)*100)
> 
> #Let's orgenize it a bit, add the names and plot
> fa.set.frq <- fa.set.frq %>%  mutate(Sqs = names(fa.set)) %>% select(Sqs,everything(), -other)%>%
+   gather(key = "Bases", value = "Frequency",2:5)
> 
> #Not the pretiest, but you can see that the one at the top left has a much lower GC contant than 
> #the rest
> ggplot(fa.set.frq, aes(x=Bases,y=Frequency))+
+   geom_bar(stat = "identity") +
+   facet_wrap(~Sqs)+
+   theme_bw()
