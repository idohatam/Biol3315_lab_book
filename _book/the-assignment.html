Biology 3315 Molecular Evolution and Phylogenetics

0.1 The assignment

Bellow are 3 problems you will have to solve in groups. The idea is that you work together to find the solution to each problem. Submit the scripts and any associated files as a group by Tue Nov 1st 23:59.

Each problem is worth 5 points

  • 1 point will go to commenting, make sure to comment properly each step in your function

  • If there is an attempt to solve the problem but no solution was made you will receive 2 additional marks on top of the marks for properly commenting the function

  • If a solution was reached you will receive four additional marks on top of the marks for properly commenting the function

  • If you feel that any of the members did not contribute at all to the assignment do not include their name and they will receive 0.

  • Remember to include a code to load any external library you used in your functions (e.g. ggplot2)

  • Remember to make sure to test for correct input by user and to use next() and break() where appropriate

  • For problems 2 and 3 assume population size is constant (i.e. does not change from generation to generation)!

  • Remember that Hardy Weinberg equation for 2 alleles is:

    • Where p is the frequency of A1 and q is the frequency of A2

\[p^2 + 2pq + q^2\]

  • Remember that:

\[\begin{align*}p+q = 1 \\p = 1-q\end{align*}\]

Problem 1

Write a function that tests for Chi square goodness of fit. The purpose of this function is to be called by the other functions you will write in this assignment, so keep testing for HW equilibrium in mind.

Remember that the formula for Chi square goodness of fit is:

\[\chi^2 = \sum_{i=1}^{k} \frac{(Obs - Exp)^2}{Exp}\]

Remember that the critical value needed to reject the null hypothesis that observed values do not differ significantly from the expected values is dependent on the number of categories you sum. This is expressed as degrees of freedom which is defined as:

\[ df = n-1 \] Where n is the number of categories, in your case the number of genotypes.

The critical value necessary to reject the null hypothesis can be retrieved using R’s qchisq function, you can call it within your function.

#Critical value for Chi square goodness of fit test, the 0.95 percentile with 
#1 - 3 degrees of freedom
#Note at how the function receives the argument, this is the critical value for a p-value equal to or smaller than 
#0.05, i.e. 5% probability to receive a larger Chi square value by chance.

qchisq(0.95, df = 1:3)
## [1] 3.841459 5.991465 7.814728

Figure out how many arguments your function will receive,(e.g. expected value, observed values, significance level etc..). Remember that the test requires number of individuals rather than proportions/frequencies so plan to account for that with respect to user input. What type of variable will each argument accept, and how will you test for correct input by the user. Think about whether you want to assign a default value to any of the arguments.

The function should return a list, which at minimum stores the following elements:

  • The significance level

  • The Chi square value

  • Number of degrees of freedom

  • Whether the null hypothesis is rejected or not

Since you will have to use it in following functions think whether require an element that can be easily accessed by a conditional statement to ask if the null hypothesis was rejected.

Problem 2

Write a function that simulates allele dynamics under positive selection of a recessive allele.

Remember that the formula to calculate the change in q under this type of selection is:

\[ \Delta{q} = \frac{pq^2s}{1+q^2s} \]

The purpose of this function is to run through a selection scenario given initial q frequency and determine at what generation a population is no longer at HW equilibrium.

At minimum the function should receive the initial proportion of q, the selection coefficient of the recessive allele, significance level for Chi square test, number of generations, and the population size.

Think about What type of variable will each argument accept, and how will you test for correct input by the user. Think about whether you want to assign a default value to any of the arguments (e.g. set a default number of generations, or a default significance level for the Chi square test). Lastly, think about how will you integrate the call of the Chi square function you wrote within the function you are currently writing, given that it requires number of individuals rather than frequencies.

The function should return a list with the following elements at minimum:

  • The initial frequency of q

  • The selection coefficient of the recessive allele

  • The population size

  • A dataframe with the columns for number of generations, frequency of q, frequency of p

    • Feel free to add additional columns if you think it necessary

  • The generation in which the population is no longer in HW equilibrium

  • A line plot generated by ggplot2 showing the frequency of each allele over time

    • The plot should include a vertical line that indicates the generation at which the population is no longer in equilibrium

    • The plot should include all generation inputted by the user even those past equilibrium

    • The plot should contain a descriptive title as well as axis titles

  • The function should also output (print) the number of generations it took for the HW equilibrium to be disrupted (with a descriptive message)

  • The function should also output the plot generated by ggplot

Run this function with s = 0.01 and the following population size: 100, 1000, 10000

Add this and the output plots to your submission

Did your result change with population size? If so, how?

Problem 3

Write a function that simulates allele dynamics under positive selection of co-dominant alleles. Remember that the formula to calculate the change in q under this type of selection is:

\[ \Delta{q} = \frac{pqs}{1+2qs} \]

The purpose of this function is to accept either a matrix or a dataframe with number of individuals per genotype, and determine if the population is under HW equilibrium. If not, determine if the allele dynamics fit the case of co-dominance.

The columns of the input table will be generation, A1A1, A1A2, A2A2. Make sure to leave a comment so that the user will know this. The function should also receive as arguments, the selection coefficient and the significance level for a Chi square test.

Think about What type of variable will each argument accept, and how will you test for correct input by the user. Think about whether you want to assign a default value to any of the arguments (e.g. default significance level). Lastly, think about how will you integrate the call of the Chi square function you wrote within your function, as you will need to call it twice here (hint calculate population size from the input table).

The function should return a list with the following elements at minimum:

  • The input table

  • The selection coefficient

  • The generation in which HW equilibrium was disrupted

    • If not, than state that it didn’t

  • The chi square value, the critical value, the degrees of freedom

  • Whether this is a co-dominance selection scenario

The function should output (print) the following information:

  • Whether or not the population is in HW equilibrium

  • What generation was the equilibrium disrupted

  • Does the allele dynamics follow a co-dominance pattern

Download the population data from BrighSpace

Run through your function and report output
