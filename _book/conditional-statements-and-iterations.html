Conditional statements and iterations

Sometimes it is necessary to ask R to decide what type of code runs on which part of the data, or how many times to run each line of code. Conditional statement such as if else, and loops are there to do just that.

Conditional statements

Conditional statements are used to determine which code will handle what part of the data. You have already used a conditional statement, even if you haven’t noticed. mutate_if is a function using a conditional statement modifying a column if a condition is met (e.g. is.numeric).

The basic conditional statement is if, it asks if a condition is met (e.g. if(x>8) = TRUE). Once the condition is met, something happens. if can be paired with an else statement to determine what to do if the condition is not met.

> # Here is an example of an if else statement note the curly brackets
> x <- 8
> 
> if (x == 8) {
+   print("x = 8")
+ } else { 
+   print("x != 8")
+   
+ }
[1] "x = 8"
> #If else statements can be chaind
> 
> if(x>8) {
+   print("x>8")
+ } else {
+   if (x == 8) {
+     print("x=8")
+   } else {
+     print("x<8")
+   }
+ }
[1] "x=8"

if else statements only work with scalars, i.e. only evaluate objects with one element. In order to evaluate a vector, the function ifelse() should be used. ifelse() takes 3 arguments, test (e.g. x>8), true (what to do in case test is true), false (what to do in case the test condition isn’t met).

The following code snippet demonstrates the use of the ifelse() function and it’s tidyverse equivalent if_else().

> #Creating a vector
> x <- sample(1:1000, 10, replace = T)
> 
> #ifelse function, if x > 500 paste something else paste somthing else to y
> y <- ifelse(x > 500, paste("x>500"), paste("x < = 500"))
> 
> #dplyr has a modefied ifelse function, it alows to handle missing values
> z <- if_else(x > 500, paste("x>500"), paste("x < = 500"))
> 
> y
 [1] "x < = 500" "x>500"     "x>500"     "x < = 500" "x>500"     "x < = 500"
 [7] "x>500"     "x < = 500" "x < = 500" "x < = 500"
> z
 [1] "x < = 500" "x>500"     "x>500"     "x < = 500" "x>500"     "x < = 500"
 [7] "x>500"     "x < = 500" "x < = 500" "x < = 500"

if_else() can also be applied to data frames as can be seen in the snippet bellow. Note, that the code uses the tidyverse if_else but base R ifelse() would work equally well.

> #If elevation is high temp is -7 else temp is 10
> 
> df2 <- df2 %>% mutate(Temp = if_else(Elevation == "High", -7, 10))
> df2

The previous example only had one condition, if the elevation is high, temp is -7, else it is 10. What if your data has more granularity, e.g. what if sea level and low elevation has a different temperature? It is possible to chain multiple ifelse() statement sequentially, in that case it is important to add a filler FALSE to the first test. Here I use NA and not a number, since that would make it easy to check whether something was missed as it would contain an NA. Note that for the first iteration I am using ifelse() andn not the dplyr if_else() because the latter is type specific and will throw an error if using input not of the same type (e.g. double and logical). This is anbother good demonstration of the diferences between base R and tidyverse approach to handling data.

> df2 <- df2 %>% mutate(Temp = ifelse(Elevation == "High", -7, NA)) %>%
+   #If test is false keep current value
+   mutate(Temp = if_else(Elevation == "Sea level", 15, Temp)) %>%
+   mutate(Temp = if_else(Elevation == "Low", 25, Temp))
> 
> df2

Alternatively, it is possible to use the if_else() function as

> #Note in second if_else, if_else is chaind in the false argument.
> #This will not work with the first one since mutate needs to create the Temp column first
> df2 <- df2 %>% mutate(Temp = ifelse(Elevation == "High", -7.5, NA)) %>%
+   mutate(Temp = if_else(Elevation == "Sea level", 15.5, 
+                         if_else(Elevation == "Low", 25.5, Temp))) 
> 
> df2
> df2 <- df2 %>% mutate(Temp = ifelse(Elevation == "High", -7.5, NA)) %>%
+   mutate(Temp = if_else(Elevation == "Sea level", 15.5, 
+                         if_else(Elevation == "Low", 25.5, Temp))) 
> 
> DT::datatable(df2)

Chaining multiple if else statements can make the code very unreadable and clumsy. The case_when() function from the dplyr package acts as a multiple if else statements and accepts multiple test arguments.

> #Let's create a new column called contamination_level and assign values based on NH4 concentrations
> 
> 
> df2 <- df2 %>% mutate(Contamination_level = case_when( NH4 > 8000 ~"Very high",
+                                                        NH4 > 7000 ~"High",
+                                                        NH4 > 6500 ~"Medium",
+                                                        NH4 < 6500 ~"Low"))
> df2

Iterations

As mentioned, R is pretty good at vectorized functions which negate the need for iterations. For example ifelse negates the need to use a loop to iterate over each position of the inspected vector. Furthermore, we have worked with functions such as summarize that iterate over an entire dataframe or replicate which can be used to to generate a list of multiple elements.

These functions were made because loops are considered memory inefficient and slow, while vectorized functions and specialized iteration functions are compiled and efficient.

However, sometimes there is no escaping the loop. The only loop we will go over in this lab is the for loop, while there are other loops in R (pun intended) in my experience they are rarely used.

The for loop has the following basic structure for(element in vector) { do something}. Normally a counting variable is used to subset elements while iterating over a vector If a counting variable is used than the vector is a range of numbers.

Here is an example of a basic for loop, note that i is used as the counting variable and there is no need to declare it.

> #Let's write a loop that picks lotomax numbers for you
> 
> 
> #Generating random numbers
> x <- sample(1:50, 8, replace = F)
> 
> #Constructing the loop
> #seq_along() generates a vector of 1:length of x
> #The reason I don't use 1:length(x) is that if the length of x is 0 the loop would still run, seq_along prevents this
> 
> for(i in seq_along(x)){
+   print(paste("The",i, "number is:", x[i], sep = " "))
+ }
[1] "The 1 number is: 5"
[1] "The 2 number is: 35"
[1] "The 3 number is: 6"
[1] "The 4 number is: 21"
[1] "The 5 number is: 36"
[1] "The 6 number is: 2"
[1] "The 7 number is: 43"
[1] "The 8 number is: 16"
> #Let's combine a conditional statement with the for loop and make a fancier number picker
> 
> for(i in seq_along(x)){
+   if(1<= i & i <8){
+   print(paste("The",i, "number is:", x[i], sep = " "))
+   } else{ 
+     print(paste("The bonus number is:", x[i], sep = " "))
+   }
+ }
[1] "The 1 number is: 5"
[1] "The 2 number is: 35"
[1] "The 3 number is: 6"
[1] "The 4 number is: 21"
[1] "The 5 number is: 36"
[1] "The 6 number is: 2"
[1] "The 7 number is: 43"
[1] "The bonus number is: 16"

The previous snippet was a pretty simple use of a for loop, now lets look at a practical way of implement it. When working as a bioinformatician you will most likely have to load and manipulate data from multiple files. In the following example I will use read.csv to import all csv files in a certain folder and place them in a list. Note that I am generating the list outside the loop, when you index an existing vector rather than add new elements to it for loops run faster.

> #Create a vector with a list of all csv files in my foulder.
> #You can use the argument path = to change foulder. 
> #recursive = F ignors subfolders
> files <- dir(pattern = ".csv", recursive = F)
> 
> lsfile <- vector(mode = "list", length = length(files))
> 
> for (i in seq_along(files)) {
+   lsfile[[i]] <- read.csv(file = files[i],row.names = 1, stringsAsFactors = F)
+   names(lsfile)[[i]] <- paste(files[i])
+   
+ }

An alternative way to do it that’s a bit more descriptive would be to use the acutall fill names by iterating over the elements of the files vectors rather than over the positions of the elements.

> files <- dir(pattern = ".csv", recursive = F)
> 
> lsfile <- vector(mode = "list", length = length(files))
> 
> #here I am declaring i
> i=1
> #Remember that the counting variable is basically, just what ever that's in the vector
> #In this case file is just the file names, btw it's not that R understand what file means
> #You could change file to pineapple and get the same result. 
> for (file in files) {
+   lsfile[[i]] <- read.csv(file = paste(file),row.names = 1, stringsAsFactors = F)
+   names(lsfile)[[i]] <- paste(file)
+   i <- i+1
+   
+ }
