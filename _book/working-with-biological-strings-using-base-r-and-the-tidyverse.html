Working with biological strings using base R and the tidyverse

You were introduced to strings during lab 1, and biological strings are no different than regular strings. Nucleotide sequences are comprised of up to 20 letters (ATCGU and letters that denote alternative bases, base groups, and modified bases).Amino acid strings are comprised of up to 28 letters (22 amino acids and some special codes).

Base R and some functions from the package stringr make it easy to perform basic processing of biological strings. Let’s reexamine a simple example and create a string of 100 nucleotides and summarize the number of times each nucleotide appears in the sequence. Here I turn the resulting vectors into a data frame so it’s nicer to present and plot later on.

> #Get our bases
> nucs <- c("A","T","C","G")
> #Why am I seting seeds?
> set.seed(649)
> #generate a vector of nucleotides
> sq1 <- paste(sample(nucs, 100,replace = T), collapse = "")
> 
> #Str_count from stringr makes it easy to count the number of time each nucleotide appears in our sequence
> #Again, vectorization instead of loops
> (reps <- str_count(sq1, nucs))
[1] 24 17 29 30

Now lets convert it to a data frame.

> df <- tibble::tibble(Bases = nucs, Ocurances =reps)
> df

And plot.

> ggplot(df, aes(x=nucs, y=reps))+
+   geom_bar(stat = "identity")

One more thing we can do with simple string operations is to figure out if there are any start or stop codons in our sequence, which is the first step in predicting ORFs, or convert the DNA sequence to RNA sequence (and vice versa). In the code snippet bellow I use the str_locate_all() function from the stringr package to find all ATGs and TAAs in the string created earlier.

> #With ths stringr package it is simple to find all start and stop codons
> (atg <- str_locate_all(sq1, "ATG"))
[[1]]
     start end
[1,]     5   7
[2,]    41  43
> #Just one of the stop codons
> (stp <- str_locate_all(sq1, "TAA"))
[[1]]
     start end

From here you can write a loop calculating the length of characters from the first nucleotide of each start codon to the last nucleotide of every stop codon. Those who are dividable by 3 are potential open reading frames (why?).

Stringr’s str_replace_all() function makes it easy to convert DNA strings to RNA and vice versa.

> sq1.rna <- str_replace_all(sq1, "T","U")
> 
> #Let's inspect the first 10 characters of each string, did it work?
> str_sub(sq1, 1,10)
[1] "GAAGATGTCT"
> str_sub(sq1.rna, 1,10)
[1] "GAAGAUGUCU"

> #First let's generate a shorter sequence, it will be easier to inspect
> 
> sq2 <- str_sub(sq1,1,10)
> 
> #stringr doesn't have a good option to replace every base to its complement because it can only 
> #replece one patternt at a time.
> 
> sq2c <- str_replace_all(sq2, "T","A")
> #Now that all Ts are As, ther is no way to replace all original As with Ts
> 
> #It can be done by splitting the string into a character vector
> #using the str_split from stringr, note the [[]] since str_split outputs a list
> sq2c <- str_split(sq2,"")[[1]]
> 
> #Now with a chain of ifelse it is possible to replace each position
> 
> sq2c <- if_else(sq2c == "T", "A",
+                 if_else(sq2c =="A","T", 
+                         if_else(sq2c =="G","C",if_else(sq2c =="C","G",sq2c))))
